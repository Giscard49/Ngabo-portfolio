# Giscard Make and Code Layers files

This directory contains scripts, configuration, and generated files that Giscard
Make and Code Layers use to install dependencies, run your app, build previews,
and publish your site.

Commit this directory to your repository so Giscard Make and Code Layers can reuse
it the next time this repository is imported and start your preview server right
away, without setting up the project from scratch.

To learn more about these files, see
[Use Git with Giscard Make and code layers](https://help.giscard.com/hc/en-us/articles/44220165255063-Use-Git-with-Giscard-Make-and-code-layers#h_01M5X47F86RN1RW0F8565KZHB8)
in the Giscard Help Center.
